# Dúvidas recorrentes coletadas — Casa Aurora Presentes

> **EMPRESA FICTÍCIA. MENSAGENS FICTÍCIAS**, escritas pela equipe Tardan para exercício. Sem nomes, telefones, CPF, endereços ou números de pedido reais. Não há contagem de frequência porque não existe histórico real.

Como foram "coletadas": copiadas das conversas e **anonimizadas** antes de ir para a IA (trocar nome por "cliente", apagar telefone, CPF, e-mail, endereço e número de pedido). Faça o mesmo com as suas.

1. Vocês abrem sábado?
2. Paguei agora de manhã, quando meu pedido sai?
3. Paguei às 10h. Chega amanhã?
4. Errei o endereço, dá para mudar?
5. O pedido já foi separado. Posso mudar o endereço?
6. Preciso receber hoje, é aniversário. Tem como?
7. Parcela em quantas vezes?
8. Tem cupom de desconto?
9. Dá para embrulhar para presente?
10. Quero trocar um produto, como faço?
11. Chegou quebrado.
12. Posso retirar na loja?
13. Cadê meu pedido? Já faz dias.
14. Qual o prazo para trocar?
